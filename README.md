# ¡Hola! Soy Juan Macario 👋

### 👨‍💻 Sobre mí
Soy un desarrollador **Full Stack** apasionado por la tecnología y la creación de aplicaciones web completas. Me muevo tanto en el **Frontend** construyendo interfaces intuitivas, como en el **Backend** diseñando arquitecturas sólidas y lógica de negocio eficientes.

Mi flujo de trabajo se basa en la **estructura y el orden**:
1. **Organizo y planifico:** Analizo la lógica del proyecto y aterrizo la arquitectura antes de escribir la primera línea de código.
2. **Construyo:** Trabajo de forma modular aislando componentes y responsabilidades para mantener un código limpio y escalable.
3. **Entrego:** Gestiono mi tiempo de forma autónoma con entregas por hitos, asegurando que cada funcionalidad esté bien probada y lista para producción.

Me enfoco en el aprendizaje continuo, la capacidad analítica para resolver problemas y la colaboración en equipo para aportar valor constante en cada proyecto.
